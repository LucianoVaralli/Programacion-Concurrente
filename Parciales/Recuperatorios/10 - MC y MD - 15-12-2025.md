## 1. SEMÁFOROS

Implemente una solución para el siguiente problema usando **SEMÁFOROS**.

Se debe simular el procesamiento de un sistema clasificador de 365 datasets meteorológicos. Todos los datasets se encuentran ya cargados en una estructura de datos. Para procesarla, el sistema dispone de 5 workers que trabajan colaborativamente procesando los datasets de a uno por vez. Cada procesamiento toma exactamente el mismo tiempo y para realizarlo los workers disponen de la función `Procesar(d)`, la cual retorna como resultado un booleano que indica si los datos corresponden a un clima tropical (`true`) o no (`false`). De acuerdo con el resultado, cada worker inserta el dataset en una cola de "tropicales" o de "no-tropicales".

> **Nota:** maximizar concurrencia.

### Resolución

```cpp
int cant_recorrer = 365/5;
int dataset[365];
sem sem_tropical = 1;
sem sem_notropical = 1;
Cola colaTropicales;
Cola colaNoTropicales;

Process worker[id: 0 .. 4] {
    bool clima;
    ini = id * cant_recorrer;
    fin = ini + cant_recorrer - 1;
    fot i: ini ... fin {
        clima = Procesar(dataset[i]);
        if(clima) {
            P(sem_tropical);
            colaTropicales.push(dataset[i]);
            V(sem_tropical);
        } else {
            P(sem_notropical);
            colaNoTropicales.push(dataset[i]);
            V(sem_notropical);
        }
    }
}
```

## 3. MONITORES

En un cine se utiliza una terminal para el canje de entradas vendidas en forma anticipada por la web. Existen N asistentes que deben usar la terminal y un Empleado del cine que administra el acceso de acuerdo con el orden dado por la edad (cuando la terminal está libre, deja pasar al de mayor edad de entre los que están esperando por usarla). La terminal sólo puede ser usada por una persona a la vez. Implemente una solución al problema con **MONITORES** utilizando procesos para representar a los Asistentes y al Empleado.

> **Notas:** existe la función `CanjearEntrada()` que representa el uso de la terminal; cada asistente conoce su edad mediante la función `obtenerEdad()`.

### Resolución

```cpp
Process asistente[id: 0 .. N] {
    int edad = obtenerEdad();
    admin.llegue(id,edad);
    CanjearEntrada();
    admin.termine(id);
}

Process empleado {
    while(true) {
        admin.atender();
    }
}

Monitor admin {
    Cola cola[int,int];
    cond atender, saliendo, esperando[N];

    procedure llegue(id: IN int, edad: IN int) {
        cola.push((id,edad));
        signal(atender);
        wait(esperando[id]);
    }

    procedure atender {
        int id;
        if(cola.isEmply()) wait(atender);
        id = cola.pop(); // saco el id
        signal(esperando[id]);
        wait(saliendo);
    }

    procedure termine() {
        signal(saliendo);
    }

}
```
